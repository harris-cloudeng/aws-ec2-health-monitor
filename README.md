
# AWS EC2 Server Health Monitoring

## Project Overview

This project aims to monitor the health and performance of a Linux server using Python and AWS services.

The goal is to collect system resource information, identify potential performance issues, and improve server monitoring through automation.

## Objectives

- Monitor CPU utilization.
- Monitor memory usage.
- Monitor disk space.
- Record monitoring results.
- Integrate AWS CloudWatch for metrics and alarms.
- Configure alerts for important server health issues.

## Technologies

- Python
- Ubuntu Linux
- Amazon EC2
- Amazon CloudWatch
- AWS Identity and Access Management (IAM)
- Git and GitHub

## Project Status

Stage 1: Project setup and documentation.

## Planned Features

1. Python-based system health monitoring.
2. Monitoring logs and error handling.
3. Deployment on an AWS EC2 Linux instance.
4. CloudWatch monitoring and alarms.
5. Notifications for critical issues.

## Security

AWS credentials and private keys must never be committed to this repository.
